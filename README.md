# Global AI Adoption in Education

## Project Overview
A Data Analytics project exploring global AI adoption in education across 10 countries from 2015 to 2026.

## Technologies Used
- Python
- Pandas
- Tableau Public
- Flask

## Project Workflow
1. Dataset Collection
2. Data Cleaning and Preprocessing
3. Exploratory Data Analysis
4. Data Visualization
5. Interactive Tableau Dashboard
6. Tableau Story
7. Flask Web Integration

## Tableau Dashboard
[View Interactive Dashboard](https://public.tableau.com/app/profile/aditi.jadhav3240/viz/Global_AI_Education_final/GlobalAIEducationIntelligenceDashboard?publish=yes)

## Dataset
The dataset contains 1360 original records covering 10 countries and the years 2015–2026.

## Run the Flask Application

Install dependencies:
pip install flask pandas

Run:
python app.py

Open http://127.0.0.1:5000
